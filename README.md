# 鋼鐵棋盤 Steel Chessboard（網頁版）

原創二戰大戰略遊戲（Godot 4.7），參考《鋼鐵雄心》類型：省分地圖、工廠與生產線、科技、國家方針、外交、
師團即時作戰（可暫停、五段速度）。國名與事件為公開史實；各國用自製色盾，不放旗幟、領袖肖像與仇恨符號。

**線上玩**：https://kevinchang0531.github.io/steel-chessboard/

- 劇本：1936 風暴前夕、1939 戰火燃起、教學：冬季戰爭；20 國可玩
- 操作：左鍵選師團、右鍵下命令、拖曳平移、滾輪縮放、空白鍵暫停、1～5 換速度
- 名字與歷史分數存在瀏覽器裡（英雄榜）
- 建議用電腦玩；網頁版沒有連線對戰（桌面版才有）

這個 repo 只放網頁匯出檔。地圖海岸線取自 Natural Earth（公有領域）；字型 Noto Sans TC（SIL OFL）；
美術由 gpt-image-2 生成、音效音樂程式合成。
